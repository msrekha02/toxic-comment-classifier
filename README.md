# Toxic Comment Classifier

A deep learning project for multi-label toxic comment classification using the Jigsaw Toxic Comment dataset.

## Models Used

* BiLSTM
* TextCNN
* CNN + BiLSTM Hybrid

## Features

* Text preprocessing and cleaning
* Multi-label classification
* ROC-AUC evaluation
* Toxicity prediction on custom comments

## Dataset

Jigsaw Toxic Comment Classification Dataset

## Technologies

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Scikit-Learn
* Matplotlib

## Results

The project compares BiLSTM, TextCNN and Hybrid architectures using ROC-AUC scores and identifies the best-performing model.
